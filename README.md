# نظام مخزون وحسابات الأخشاب

نظام ويب عربي (RTL، خط Cairo) لشركة أخشاب: المخزون بالعدد والحجم بالمتر المكعب بدقة كاملة، مع الحسابات والتقارير، لعدة فروع ومخازن ومستخدمين، وتحديث فوري للصفحات.

- PHP 8.1+ مع MySQL/MariaDB عبر PDO.
- بدون إطار عمل وبدون خطوة بناء، وجاهز للاستضافة المشتركة (Hostinger). المكتبات الخارجية (mPDF) مضمنة في `app/vendor`.

**الإصدار:** 2.0.0.

## المزايا

| المجال | المحتوى |
|---|---|
| المخزون | وارد وبيع وتحويل متعدد الأسطر بالعدد، وحجم وقيمة دقيقة، وأرصدة لكل مخزن، وإلغاء يحفظ المستند |
| المبيعات والمشتريات | عميل أو مورد من قائمة، ودفع نقدي أو آجل أو جزئي، وحد ائتمان، ومراجعة قبل التأكيد |
| التكلفة | متوسط مرجح لكل صنف، وربح كل فاتورة، وتقييم افتتاحي للمخزون |
| الحسابات | العملاء والموردون، والخزائن، وتصنيفات المصروفات، وسندات القبض والصرف والمصروف وتحويل النقدية، وكشوف الحساب، والمبلغ بالحروف |
| التقارير | لوحة تحكم، ومبيعات، وأرباح، وتقييم مخزون، وأرصدة، وخزائن، ومصروفات |
| الجداول والتصدير | ترتيب، واختيار أعمدة، وبحث سريع، وتصدير Excel وCSV وتقرير PDF، وPDF للفاتورة |
| المستخدمون | أدوار مدير وموظف، ونطاق فرع لكل مستخدم، وسجل مراقبة كامل |
| الحماية | تحقق بخطوتين، وحد لمحاولات الدخول، وCSRF، وCSP، وجلسات مربوطة بالمتصفح، وفلتر برامج الأتمتة |
| الواجهة | متجاوبة للهاتف والتابلت والكمبيوتر، وتحديث فوري بين الأجهزة |

## الهيكل

```
public_html/                 ← هذا ما يُرفع للاستضافة (أو ملف ZIP من dist/)
├── index.php                ← نقطة الدخول الوحيدة للصفحات (?r=...) وجدول ROUTES
├── install.php              ← التثبيت لمرة واحدة واستعادة كلمة المرور، يحذف نفسه
├── .htaccess                ← حماية app/ والملفات الحساسة والسكربتات
├── assets/                  ← css و js وخط Cairo المحلي (woff2)
└── app/                     ← غير قابل للفتح من المتصفح
    ├── config.sample.php    ← نموذج الإعدادات (بدون أسرار)
    ├── bootstrap.php
    ├── migrations/          ← ترقيات قاعدة البيانات 001 إلى 006
    ├── lib/                 ← الحساب الدقيق، والمستندات، والحسابات، والتكلفة، والحماية، والتصدير، والعرض
    ├── pages/               ← الصفحات
    ├── vendor/              ← mPDF ومتطلباتها (PDF)
    ├── fonts/               ← خط Cairo بصيغة TTF لملفات PDF
    └── storage/             ← السجلات والجلسات وملف قفل التثبيت
tests/                       ← الاختبارات (لا تُرفع)
tools/                       ← بناء ملف الرفع
```

أهم ملفات `app/lib`: `documents.php` (المستندات والإلغاء)، و`accounting.php` (المبالغ والدفاتر وتاريخ الإقفال)، و`costing.php` (المتوسط المرجح)، و`parties.php` و`cashboxes.php` و`vouchers.php` (الحسابات)، و`acct_reports.php` (التقارير المحاسبية)، و`tables.php` و`exports.php` (أدوات الجداول والترتيب والتصدير)، و`pdf.php` (ملفات PDF)، و`auth.php` و`security.php` و`totp.php` (الدخول والحماية)، و`xlsx.php` (Excel وCSV).

## قرارات تقنية أساسية

- **الحساب الدقيق:** الأبعاد أعداد صحيحة بالميكرومتر، والأحجام `DECIMAL(…,18)`، والمبالغ بالقروش كأعداد صحيحة في PHP و`DECIMAL(24,2)` في القاعدة. لا يُستخدم float في أي حساب (`Num` في PHP و`BigInt` في JavaScript).
- **الأرصدة:** المخزون في `stock`، وأرصدة العملاء والموردين والخزائن تتغير فقط عبر الدفاتر `party_ledger` و`cash_ledger`، فيبقى دائمًا: الرصيد = الافتتاحي + مجموع القيود.
- **المعاملات:** كل عملية معاملة InnoDB واحدة بترتيب أقفال ثابت (موثق في رأس `accounting.php`)، والرصيد الملزم يُقرأ بعد `SELECT … FOR UPDATE`.
- **الإلغاء:** لا حذف لأي مستند أو قيد. قيود عكسية بتاريخ الإلغاء.
- **منع التكرار:** رمز طلب فريد مع بصمة المحتوى، وترقيم متتالٍ بلا فجوات لكل نوع.
- **الصلاحيات:** تُفحص على الخادم لكل صفحة ولكل عملية، وأي صفحة غير مسجلة في خريطة الصلاحيات للمدير فقط.
- **التحديث الفوري:** رقم `data_version` يرتفع داخل كل معاملة حفظ. الصفحات تفحصه كل ثانيتين (وكل 10 ثوانٍ بعد 10 دقائق بلا نشاط، ولا تفحصه والتبويب مخفي)، ومزامنة بين التبويبات عبر BroadcastChannel، وتستبدل المناطق المتغيرة فقط دون لمس ما يكتبه المستخدم.

## تشغيل الاختبارات (بيئة التطوير فقط)

```bash
tests/run_all.sh         # كل الاختبارات بالترتيب، على ملف ZIP المبني نفسه
```

كل اختبار يكتب مخرجاته الكاملة في `tests/output/<الاسم>.log`. لتشغيل اختبار واحد:

| الأمر | ماذا يختبر |
|---|---|
| `php tests/unit.php` | الحساب الدقيق والتحويل بين الوحدات والتنسيق |
| `php tests/unit_totp.php` | رموز التحقق بخطوتين |
| `php tests/unit_security.php` | فلتر برامج الأتمتة، وحدود محاولات الدخول، وربط الجلسة ومدتها، وخطوة رمز التحقق |
| `node tests/parity.cjs` | تطابق حساب JavaScript مع PHP |
| `node tests/live_timing.cjs` | توقيت التحديث الفوري |
| `php tests/integration.php` | المستندات والإلغاء والتزامن على قاعدة حقيقية |
| `php tests/integration_auth_events.php` | سجل الدخول والأمان |
| `php tests/accounting_foundation.php` | أساس الحسابات والدفاتر |
| `php tests/integration_sales_purchases.php` | البيع والشراء بالدفع والمتوسط المرجح |
| `php tests/integration_vouchers.php` | السندات والخزائن والكشوف والتزامن |
| `php tests/integration_acct_reports.php` | التقارير المحاسبية ولوحة التحكم |
| `php tests/xlsx.php` | ملفات Excel وCSV |
| `python3 -I tests/http_security.py` | الحماية عبر HTTP على خادم حقيقي |
| `python3 -I tests/http_auth_events.py` | أحداث الدخول عبر HTTP |
| `python3 -I tests/http_permissions.py` | صلاحيات المدير والموظف عبر HTTP |
| `python3 -I tests/http_branches.py` | الفروع ونطاقها عبر HTTP |
| `python3 -I tests/http_exports.py` | التصدير (Excel وCSV وPDF) والترتيب والأعمدة والحدود والمراقبة، وPDF الفاتورة |
| `node tests/e2e.mjs` | المتصفح الكامل (Playwright) |
| `node tests/ui_responsive.mjs` | الواجهة على 7 مقاسات (بعد e2e على نفس الموقع) |

اختبارات HTTP والمتصفح تحتاج `tests/deploy.sh [ملف ZIP]` قبلها (قاعدة `wood_e2e` جديدة). اختبار المتصفح يحتاج `LANG=C.UTF-8` (مضبوط في `run_all.sh`)، وإلا يسمي Chromium ملفات التحميل العربية «download».

المتطلبات:
- MariaDB محلي، ومستخدم `wood_app`.
- Apache مع mod_php ووحدة `tests/apache-wood.conf` على المنفذ 8080 (`tests/deploy.sh` ينشر ملف ZIP عليه).
- Node 22 مع Playwright وChromium، وeslint.
- Python 3.

التفاصيل والنتائج في `TEST_REPORT.md`.

## بناء ملف الرفع

```bash
tools/build-zip.sh       # ينتج dist/wood-inventory-<الإصدار>-upload.zip و SHA256SUMS
```

الإصدار يُقرأ من `APP_VERSION` في `app/lib/core.php`.
