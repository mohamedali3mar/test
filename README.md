# نظام مخزون ومبيعات الأخشاب

نظام ويب عربي (RTL، خط Cairo) لشركة أخشاب. الوارد والبيع والتحويل بالعدد، والحجم والقيمة بالمتر المكعب بدقة كاملة، مع عدة مخازن وتحديث تلقائي للصفحات.

- PHP 8.1+ مع MySQL/MariaDB عبر PDO.
- بدون إطار عمل وبدون خطوة بناء، وجاهز للاستضافة المشتركة (Hostinger).

**الإصدار:** 1.0.0. هذه المرحلة الأولى: المخزون والمخازن والتحويل وفواتير البيع. المرحلة الثانية: الحسابات.

## الهيكل

```
public_html/                 ← هذا ما يُرفع للاستضافة (أو ملف ZIP من dist/)
├── index.php                ← نقطة الدخول الوحيدة للصفحات (?r=...)
├── install.php              ← التثبيت لمرة واحدة واستعادة كلمة المرور، يحذف نفسه
├── .htaccess                ← حماية app/ والملفات الحساسة
├── assets/                  ← css و js وخط Cairo المحلي
└── app/                     ← غير قابل للفتح من المتصفح
    ├── config.sample.php    ← نموذج الإعدادات (بدون أسرار)
    ├── bootstrap.php
    ├── migrations/          ← ترقيات قاعدة البيانات (001_initial.sql ينشئ كل الجداول)
    ├── lib/                 ← الحساب الدقيق، والخدمات، والحماية، والعرض
    ├── pages/               ← الصفحات
    └── storage/             ← السجلات والجلسات وملف قفل التثبيت
tests/                       ← الاختبارات (لا تُرفع)
tools/                       ← بناء ملف الرفع
```

## قرارات تقنية أساسية

- **الحساب الدقيق:**
  - الأبعاد أعداد صحيحة بالميكرومتر.
  - الأحجام `DECIMAL(…,18)` دقيقة تمامًا.
  - الحساب في PHP وJavaScript بأعداد صحيحة كبيرة: الكلاس `Num` في PHP، و`BigInt` في JavaScript. لا يُستخدم float في أي حساب.
- **هوية الصنف:** مفتاح فريد على (النوع، العرض، التخانة، الطول) بعد التوحيد.
- **الرصيد:** مخزن في جدول `stock` لكل صنف في كل مخزن.
- **المستندات:**
  - كل مستند رأس (`documents`) وأسطر (`document_lines`).
  - كل عملية معاملة InnoDB واحدة، والأقفال بترتيب ثابت.
  - الرصيد الملزم يُقرأ بعد `SELECT … FOR UPDATE`.
  - ترقيم متتالٍ بلا فجوات لكل نوع.
- **منع التكرار:** رمز طلب فريد مع بصمة المحتوى.
- **التحديث التلقائي:**
  - رقم `data_version` يرتفع داخل كل معاملة حفظ.
  - الصفحات تفحصه كل ثانيتين، وكل 10 ثوانٍ بعد 10 دقائق بلا نشاط، ولا تفحصه والتبويب مخفي. وتفحصه فورًا عند الرجوع إلى التبويب أو عودة الاتصال، وعند الحفظ في تبويب آخر من نفس المتصفح (BroadcastChannel). بعد الإخفاق تتباعد المحاولات حتى 30 ثانية.
  - تستبدل المناطق المتغيرة فقط دون لمس ما يكتبه المستخدم أو موضع التركيز، ولا تعيد جلب الصفحة ما دامت المنطقة المؤجلة مشغولة.

## تشغيل الاختبارات (بيئة التطوير فقط)

```bash
tests/run_all.sh         # وحدة + تطابق JS + تكامل + eslint + HTTP + متصفح، على ملف ZIP المبني
```

المتطلبات:
- MariaDB محلي، ومستخدم `wood_app`.
- Apache مع mod_php ووحدة `tests/apache-wood.conf` على المنفذ 8080.
- Node 22 مع Playwright وChromium.

التفاصيل في `TEST_REPORT.md`.
